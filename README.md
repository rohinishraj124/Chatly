# Chatly 💬

**Chatly** is a real-time messaging application built with the MERN stack (MongoDB, Express, React, Node.js) and Socket.io. It features secure authentication, image sharing, theme customization, and a request-based chat system to ensure privacy.

## ✨ Features

- **Real-time Messaging**: Instant message delivery using **Socket.io**.
- **Secure Authentication**: User Signup, Login, and Logout functionality using **JWT** and **BCrypt**.
- **Chat Requests System**:
  - Users must send a chat request to start a conversation.
  - Receivers can **Accept** or **Reject** requests.
  - Messages are only allowed after a request is accepted.
- **Media Support**: Image uploads and sharing powered by **Cloudinary**.
- **User Presence**: Real-time online/offline status updates.
- **Theme Customization**: Built-in theme switcher (Light, Dark, and more) using **DaisyUI**.
- **Responsive UI**: Fully responsive design built with **TailwindCSS**.
- **State Management**: Efficient state handling with **Zustand**.

## 🛠️ Tech Stack

### Frontend
- **React** (Vite)
- **TailwindCSS** & **DaisyUI** (Styling)
- **Zustand** (State Management)
- **Socket.io-client** (Real-time communication)
- **Axios** (API requests)
- **React Hot Toast** (Notifications)

### Backend
- **Node.js** & **Express.js**
- **MongoDB** & **Mongoose** (Database)
- **Socket.io** (WebSockets)
- **JWT** (Authentication)
- **Cloudinary** (Image Storage)
- **Cookie-parser** (Secure cookies)
